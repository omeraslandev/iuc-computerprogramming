## 1. BÖLÜM: Veri Tipleri Hiyerarşisi ve Bellek Bölgeleri

### 1.1. Veri Tipleri Şeması

```
                    ┌─────────────────┐
                    │   Veri Tipleri  │
                    └────────┬────────┘
                             │
            ┌────────────────┴────────────────┐
            ▼                                 ▼
   ┌─────────────────┐               ┌──────────────────┐
   │  Değer Tipleri  │               │ Referans Tipleri │
   └────────┬────────┘               └──────────────────┘
            │
   ┌────────┴────────┐
   ▼                 ▼
┌──────┐      ───────────────
│Temel │      │  Kullanıcı  │
│Veri  │      │ Veri Tipleri│
│Tipleri      ───────────────
└──────┘
```

### 1.2. Bellek Bölgeleri (Memory Regions)

- **Stack Bölgesi** $\rightarrow$ Tamsayı türünden (ve değer tipleri) tutulur.
- **Heap Bölgesi** $\rightarrow$ `new` anahtar sözcüğü ile oluşturulan nesneler tutulur.
- **Register Bölgesi**
- **Static Bölge**
- **Sabit Bölge** $\rightarrow$ Veriler sabittir.
- **RAM Olmayan Bölge**

## 2. BÖLÜM: Değişken Tanımlama ve Faaliyet Alanı (Scope)

### 2.1. Değişken Tanımlama Kuralları

**Sözdizimi (Syntax):**

```
<veri türü> <ismi>
```

- **!** Eğer bir değişkeni kullanmak istiyorsak değişkenlere bir değer verilmesi zorunludur. Bu kural değer ve referans tipleri için de geçerlidir.
- **!** Büyük-küçük harf duyarlılığı (case-sensitivity) vardır.
- **!** Boşluk (space) kullanılmaz.

### 2.2. Faaliyet Alanı (Scope)

- Değişkenin belirli bir scope bölgesi vardır. Tanımlanan değişkene ancak tanımlanmış blok (scope) içerisinde erişebiliriz.

### 2.3. Bellek Tutulum İlkeleri

- **Değer Tipleri** $\rightarrow$ **Stack** bölgesinde tutulur.
- **Referans Tipleri** $\rightarrow$ **Heap** bölgesinde tutulur.

### 2.4. Değer Tipi & Referans Tipi Örnek Çizimleri

#### **A) Değer Tipi (Stack Bellek Temsili)**

**Kod Bloğu:**

```
int a = 5;
int b = a;
a = 258;
```

**Stack Bellek Durumu:**

```
 ┌──────────────────────┐ (Değer Tipi - Stack)
 │  a   │    258        │
 ├──────┼───────────────┤
 │  b   │      5        │
 └──────┴───────────────┘
```

_(Değer tiplerinde atama kopyalama usulüyle yapılır; `a` değişkeninin değeri değiştirildiğinde `b` bundan etkilenmez.)_

#### **B) Referans Tipi (Stack & Heap Bellek Temsili)**

**Kod Bloğu:**

```
string i = "deneme";
string j = i;

i = "deneme 2";
// ↳ j'nin de değeri değişir!
```

**Bellek Temsili:**

```
  [ Stack ]                   [ Heap ]
┌───────────┐             ┌───────────────┐
│     i     │ ──────────► │  "deneme 2"   │
├───────────┤             └───────────────┘
│     j     │ ──────────────────▲
└───────────┘
```

_(Referans tiplerinde değişkenler bellekteki aynı adresi/veriyi işaret eder.)_


## 3. BÖLÜM: Değer Tipi vs. Referans Tipi Karşılaştırmalı Kod Ve Bellek Analizi

```
+---------------------------------------+-------------------------------------+
| # Değer Tipi                          | # Referans Tipi                     |
+---------------------------------------+-------------------------------------+
| KOD:                                  | KOD:                                |
|   int i = 17;                         |   string s = "Hello";               |
|   int j = i;                          |   string s1 = s;                    |
|                                       |                                     |
| BELLEK ÇİZİMİ (STACK):                | BELLEK ÇİZİMİ (STACK & HEAP):       |
|                                       |                                     |
|   +---+----+                          |   +----+---+                        |
|   | i | 17 |                          |   | s  |   |----+                   |
|   +---+----+                          |   +----+---+    |   +-----------+   |
|   | j | 17 |                          |   | s1 |   |----+-->|   Hello   |   |
|   +---+----+                          |   +----+---+        +-----------+   |
|                                       |                       (Heap)        |
|                                       |                                     |
| AÇIKLAMA:                             | AÇIKLAMA:                           |
| Değer tipindeki 'i' ve 'j'            | Referans tipindeki 's' ve 's1'      |
| değişkenlerinin her ikisi de Stack    | değişkenleri Stack'te tutulur,      |
| bölgesinde bağımsız hücrelerde kendi  | gösterdikleri "Hello" metin değeri  |
| değerlerini (17) saklar.              | ise Heap bölgesinde tutulur.        |
+---------------------------------------+-------------------------------------+
```
