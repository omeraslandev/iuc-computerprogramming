## 1. BÖLÜM: TEMEL BİLEŞENLER VE KULLANICI ETKİLEŞİMİ

#### Sistem Bileşenleri

1. **Donanım (Hardware)**
    - **CPU:** Temel işlem birimi.
    - **Hafıza / Bellek:** RAM.
    - **I/O (Giriş/Çıkış):** Bilgisayar ile iletişim kurmak için kullanılan birimler.
2. **OS (İşletim Sistemi / Operating System)**
    - Donanım ve uygulama yönetimini sağlar.
3. **Apps (Uygulamalar)**
    - Kullanıcının iş, eğlence, hesaplama ihtiyaçlarını karşılar (ör. _Hesap Makinesi_, _Kullanıcı / Klasik Uygulamalar_).
4. **Users (Kullanıcılar)**

#### Kullanıcı ve Donanım Arasındaki Etkileşim Akışı

$$\text{Kullanıcı} \iff \text{Apps (Uygulamalar)} \iff \text{OS (İşletim Sistemi)} \iff \text{Donanım}$$

## 2. BÖLÜM: BİLGİSAYAR (PC) MİMARİSİ VE DONANIM BİLEŞENLERİ
  

### Bilgisayar Yapısı (Ağaç Hiyerarşisi)

```
                       [ PC ]
                         |
        +----------------+----------------+
        |                                 |
  [ H (Hardware) ]                [ S (Software) ]
        |                                 |
  +-----+-----+                     +-----+-----+
  |           |                     |           |
[Dış H]     [İç H]                [OS]        [APPS]
  |           |                     |           |
  +-- Fare    +-- RAM               +-- Linux   +-- LibreOffice
  +-- Klavye  +-- CPU               +-- Mac     +-- vb.
  +-- vb.     +-- vb.               +-- Windows
                                    +-- vb.
```

### Donanım Ünitelerinin Sınıflandırılması

- **Sistem Ünitesi (System Unit):**
    - CPU (İşlemci)
    - Ana Kart (Motherboard)
- **Giriş Ünitesi:**
    - Klavye
    - Fare
- **Çıkış Ünitesi:**
    - Ekran (Monitör)
    - Yazıcı
- **Depolama Ünitesi:**
    - Sabit Disk (Hard Disk)
    - Flash Disk
- **Diğer Aygıtlar**

## 3. BÖLÜM: YAZILIM TÜRLERİ VE BELLEK AKIŞI

### Yazılım Sınıflandırması

```
                            [ Yazılım ]
                                 |
    +-----------------+----------+----------+-----------------+
    |                 |                     |                 |
 [ OS ]       [ Prog. Dilleri ]        [ Driver ]         [ BIOS ]
                      |
              +-------+-------+
              |       |       |
          Derleyici Yorumlayıcı Çevirici
```

### Depolama Hiyerarşisi ve İşlemci İlişkisi Notları

- **CPU (İşlemci) talimatları yalnızca bellekten yükleyebilir.**
- **İşlemciyi Besleme Akışı:**
    $$\text{(CPU)} \iff \text{(RAM / Ana Bellek)} \iff \text{(Sabit Disk / Depolama)}$$
    

## 4. BÖLÜM: DEPOLAMA HİYERARŞİSİ VE BELLEK TÜRLERİ


### Bellek Türleri Tanımları

- **ROM (Read-Only Memory):** Salt okunur bellek tipidir. Statik programlar burada saklanır.
- **EEPROM (Electrically Erasable Programmable Read-Only Memory):** Elektrikle silinebilir ve yeniden programlanabilir salt okunur bellek.

### Depolama Hiyerarşisi Piramidi


```
  /-------------------------\   <- [ Registers (Yazmaçlar) ]
 /---------------------------\  <- [ Cache (Önbellek) ]
/-----------------------------\ <- [ Main Memory (Ana Bellek / RAM) ]
|-----------------------------| <- [ Electronic Disk (SSD/Flash) ]
|-----------------------------| <- [ Magnetic Disk (Sabit Disk) ]
|-----------------------------| <- [ Optical Disk (CD/DVD) ]
\-----------------------------/ <- [ Magnetic Tapes (Teyp/Şerit) ][cite: 1, 2]
 \---------------------------/
```

**Hiyerarşi düştükçe:**

- Bit başına maliyet düşer.
- Depolama kapasitesi artar.
- Erişim hızı azalır (yavaşlar).

**Hiyerarşi yükseldikçe:**

- Bit başına maliyet artar (daha pahalı hale gelir).
- Erişim hızı artar (daha hızlı çalışır).
- Depolama kapasitesi azalır.


## 5. BÖLÜM: İŞLETİM SİSTEMİ MİMARİSİ VE KATMANLARI


### Bilgisayar Sistemi Mimarisi Kavramları

- **Multiuser:** Çoklu kullanıcı desteği.
- **Multiprocessing:** Çoklu işlemcili işletim sistemi kullanımı.
- **Multitasking:** Çoklu görev çalıştırma özelliği.
- **Multithreading:** Çoklu iş parçacığı çalıştırma.
    - _Thread Definition:_ C dilinde / sistemde eş zamanlı olarak işlenen her bir program bölümüdür.

### Çalışan Bilgisayar Süreç (Process) ve İş Parçacığı (Thread) Şeması


```
                   [ Computer Runs ]
                           |
        +----------+-------+-------+----------+
        |          |               |          |
     [Task 1]   [Task 2]        [Task 3]   [Task 4]
                (RUNS)
                   |
       +-----------+-----------+
       |           |           |
   [THREAD 1]  [THREAD 2]  [THREAD 3]
```

### Katmanlı Sistem Yapısı (Mimari Mimari)


```
+------------------------------------------+
| Kullanıcı (User)                         |
+------------------------------------------+
| Kabuk (Shell)                            |
+------------------------------------------+
| Sistem Çağrıları (System Calls)         |
+------------------------------------------+
| Çekirdek (Kernel)                        |
+------------------------------------------+
| Donanım (Hardware)                       |
+------------------------------------------+
```

## 6. BÖLÜM: SHELL (KABUK) VE KERNEL (ÇEKİRDEK)


### 1) Kabuk (Shell)

- `cmd` (Terminal) veya GUI (Grafik Kullanıcı Arayüzü) ile genişletilebilir.
    
- **Farklı Shell Türleri:**
    - `sh`
    - `csh`
    - `ksh`
    - `bash`
    - `zsh`

### 2) Çekirdek (Kernel)

- **Çekirdeğin Ana Görevleri:**
    - Belleği yönetmek.
    - Sistem kaynaklarını yönetmek.
    - Interrupt'ları (kesmeleri) kullanmak.
    - Hataları kontrol etmek.
    - I/O (Giriş/Çıkış) birimlerini çalıştırmak.
    - Dosya sistemini oluşturmak ve kullanmak.

## 7. BÖLÜM: İŞLETİM SİSTEMİ İŞLEVLERİ VE DOSYA YÖNETİMİ


### İşletim Sistemi İşlevleri ve Dosya Yönetim Sistemi

Sistemdeki veri kümeleri **dosya (kütük)** olarak adlandırılır.

- **Sürücü:** Dosya ve klasörlerin saklanabileceği fiziksel/anlamsal ortamlardır.
- **Klasör (Dizin):** Dosyaları gruplamak için kullanılan yapılardır.
- **Dosya:** Çalışmaları ve verileri kaydetmek için kullanılan temel birimlerdir.

## 8. BÖLÜM: İSİMLENDİRME KURALLARI VE İŞLETİM SİSTEMİ GÖREVLERİ


### Dosya ve Klasör İsimlendirme Kuralları

Sistem kısıtlamalarından dolayı bazı özel isimler dosya veya klasör ismi olarak **kullanılamazlar**:

- **Ayrılmış İsimler:**
    - `con`
    - `com0`, `com1`, `com2`, ..., `com9`
    - `aux`
    - `prn`
    - `nul`

### İşletim Sisteminin Temel Görev Özeti

1. **Yardımcı Programları Destekleme Görevi**
2. **Bilgisayar Donanımını Kontrol Etme Görevi**

## 9. BÖLÜM: BIOS VE MİKROPROGRAMLAMA KATMANLARI


### BIOS ve I/O Mantığı

- **BIOS:** _Basic Input/Output System_ (Temel Giriş/Çıkış Sistemi).
- **EPROM** yongası üzerinde **ROM** bellekte saklanır.

### Donanım ve Yazılım Seviyeleri Hiyerarşisi

```
+-------------------------------------------------------+
|  App 1  |  App 2  |  App 3  |  ... (Uygulamalar)      |
+-------------------------------------------------------+
|  OS (İşletim Sistemi)                                 |
+-------------------------------------------------------+
|  Makine Dili (Machine Language)                       |  <--- Donanım
+-------------------------------------------------------+       Sınırı
|  Mikroprogram (Microprogram)                          |
+-------------------------------------------------------+
|  Fiziksel Birimler (Physical Hardware / Logic Gates)  |
+-------------------------------------------------------+
```

- **Açıklama Notu:** Mikroprogram, donanım seviyesinde yorumlanmış doğru komut setini işletir.
