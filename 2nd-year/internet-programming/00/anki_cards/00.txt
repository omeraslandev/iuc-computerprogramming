HTML'de paragraf metni yazmak için {{c1::<p>}} etiketi kullanılır.	HTML Paragraf

HTML öğelerinin üzerine fare imleciyle gelindiğinde bilgi kutucuğu (tooltip) açılmasını sağlayan nitelik {{c1::title}} niteliğidir.	HTML Tooltip
HTML'de metni kalın (bold) yapmak için {{c1::<b>}} etiketi kullanılır.	HTML Metin Biçimlendirme

HTML'de metnin altını çizmek (underline) için {{c1::<u>}} etiketi kullanılır.	HTML Metin Biçimlendirme
HTML'de metni vurgulu kalın yapmak için {{c1::<strong>}} etiketi kullanılır.	HTML Metin Biçimlendirme
HTML'de sayfaya yatay çizgi çekmek için {{c1::<hr>}} etiketi kullanılır.	HTML Yatay Çizgi
HTML'de üslü ifadeler gibi üst simgeler oluşturmak için {{c1::<sup>}} etiketi kullanılır.	HTML Üst Simge
HTML'de kimyasal moleküller gibi alt simgeler oluşturmak için {{c1::<sub>}} etiketi kullanılır.	HTML Alt Simge
Bir metne aynı anda birden fazla biçimlendirme uygulamak için etiketler {{c1::iç içe}} kullanılır.	HTML İç İçe Etiketler
Klasik HTML'de yazı tipi, renk ve boyut ayarlamak için kullanılan ancak HTML5'te yerini CSS'e bırakan etiket {{c1::<font>}} etiketidir.	HTML Font Etiketi
HTML font etiketinde metin boyutunu ayarlamak için {{c1::size}} niteliği kullanılır.	HTML Font Boyutu
HTML font etiketindeki size niteliği {{c1::1}} (en küçük) ile {{c2::7}} (en büyük) arasında değer alır.	HTML Font Boyut Değerleri
HTML font etiketinde metin rengini ayarlamak için {{c1::color}} niteliği kullanılır.	HTML Font Rengi

HTML font etiketinde yazı tipini (Arial, Monospace vb.) belirlemek için {{c1::face}} niteliği kullanılır.	HTML Yazı Tipi
Modern HTML'de sayfa içi çapa (anchor) noktası oluştururken tercih edilen nitelik {{c1::id}} niteliğidir.	HTML Çapa Noktası

HTML'de dış veya iç bağlantılar (link) oluşturmak için {{c1::<a>}} etiketi kullanılır.	HTML Bağlantı
HTML bağlantı etiketinde hedef adresi/URL'yi belirtmek için {{c1::href}} niteliği kullanılır.	HTML Bağlantı Adresi
HTML bağlantılarda linkin aynı sekmede açılmasını sağlayan varsayılan target değeri {{c1::_self}} değeridir.	HTML Bağlantı Hedefi
HTML bağlantılarda linkin yeni bir sekmede açılmasını sağlayan target değeri {{c1::_blank}} değeridir.	HTML Bağlantı Hedefi
